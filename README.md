## 📘 Repository Overview

This repository contains the **sessional laboratory reports** for the course **ECE 2112 — Digital Techniques** offered by the Department of Electrical & Computer Engineering at Rajshahi University of Engineering & Technology (RUET).

The reports document the theoretical analysis, Boolean simplification, Karnaugh-map techniques, circuit design, logic simulation, verification, discussion, and conclusions for the corresponding laboratory experiments.

The work is organized to maintain a clear and systematic record of each experiment, with emphasis on both **theoretical correctness** and **practical verification**.

## 🔬 Report Structure

Each laboratory report is organized in a consistent academic format:

1. **Problem Statement**
2. **Objective**
3. **Required Theory / Background**
4. **Boolean Algebraic Simplification**
5. **Truth Table**
6. **Karnaugh Map**
7. **Circuit Diagram**
8. **Logic Simulation**
9. **Results and Verification**
10. **Discussion**
11. **Conclusion**

This structure ensures that each experiment presents both the **mathematical derivation** and the **practical implementation** in a clear and verifiable manner.

---

## 🧪 Tools & Methods

The laboratory work primarily involves:

* **Boolean Algebra**
* **Karnaugh Maps (K-Maps)**
* **Logic Gate Design**
* **Truth Table Analysis**
* **Digital Circuit Implementation**
* **Logisim Simulation**
* **Functional Verification**

---

## ✅ Verification Approach

For each experiment, the simplified Boolean expression is verified through multiple methods wherever applicable:

**Algebraic Method → K-Map Method → Circuit Implementation → Logic Simulation**

The original and simplified circuits are compared for all possible input combinations to ensure that the simplification preserves the original circuit's functionality.
